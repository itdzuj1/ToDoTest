# Admin API — изменения API

## Затронутые эндпоинты

Добавлены защищённые admin endpoint-ы:

- `GET /api/admin/dashboard`;
- `GET /api/admin/users`;
- `GET /api/admin/users/{user}`;
- `PATCH /api/admin/users/{user}/block`;
- `PATCH /api/admin/users/{user}/unblock`;
- `PATCH /api/admin/todo-lists/{todoList}/archive`;
- `PATCH /api/admin/todo-lists/{todoList}/restore`;
- `GET /api/admin/todo-lists/{todoList}/tasks`;
- `PATCH /api/admin/tasks/{task}`;
- `DELETE /api/admin/tasks/{task}`.

## Изменения в ответе

| Поле / ответ | Было | Стало | Примечание |
|---|---|---|---|
| `GET /api/admin/dashboard` | — | object `data` с агрегатами | **добавлено** |
| `GET /api/admin/users` | — | пагинированная `UserResource` | без `todo_lists` |
| `GET /api/admin/users/{user}` | — | `UserResource` + `todo_lists` | задачи не вложены |
| `PATCH .../block\|unblock` | — | `UserResource` | идемпотентно |
| `PATCH .../archive\|restore` | — | `TodoListResource` | идемпотентно |
| `GET .../todo-lists/{todoList}/tasks` | — | пагинированная `TaskResource` | с `tags` |
| `PATCH /api/admin/tasks/{task}` | — | `TaskResource` | с `tags` |
| `DELETE /api/admin/tasks/{task}` | — | HTTP 204 | hard delete |

Агрегаты dashboard:

- `users_count`
- `active_lists_count`
- `archived_lists_count`
- `tasks_count`
- `overdue_tasks_count`

## Изменения в запросе

`GET /api/admin/users` принимает:

- `search` — опциональная строка до 80 символов;
- `filter=active|blocked|all`, по умолчанию `all`;
- `per_page` — 1..100, по умолчанию 20;
- `page` — номер страницы.

`GET /api/admin/todo-lists/{todoList}/tasks` принимает те же query-параметры, что публичный
list задач.

`PATCH /api/admin/tasks/{task}` принимает:

- `title`, `description`, `status`, `priority`, `due_at`, `tag_ids`.

## Breaking changes

Нет. Публичный API не изменён.

## Migration notes для фронта

- Все admin endpoint-ы требуют cookie-сессию и CSRF для mutating-запросов.
- Детальный просмотр пользователя не включает задачи: задачи загружаются отдельно через
  `GET /api/admin/todo-lists/{todoList}/tasks`.
- Админ может редактировать и удалять задачи в архивных списках и у blocked-профилей.
- Подтверждение безвозвратного удаления задачи остаётся на стороне UI.
- Полный CRUD пользователей и списков в первой версии не предоставляется.
