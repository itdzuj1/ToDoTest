# Визуальная концепция

Плотный B2B productivity-интерфейс на белом канвасе. Монохромная база (#202020 на #ffffff), тонкие границы 1px, pill-геометрия для всех интерактивных ярлыков, два контролируемых акцента.

## Принципы
1. **Иерархию держит типографика и ритм**, а не цвет и не тени. Тени только у оверлеев и приподнятых карточек.
2. **Акцент дозирован.** Фиолетовый #6647f0 — идентичность, выбранное состояние, brand-CTA. Синий #0091ff — ссылки и фокус. Всё остальное — нейтрали.
3. **Плотность важнее воздуха.** Строка таблицы public 48px, admin 44px; контролы 32/36/40px.
4. **Заголовки плотные:** font-weight 650–800, letter-spacing ≈ −0.04em.
5. **Крупные размеры (60–80px)** — только profile selection и admin login. Рабочие экраны — 34–48px.
6. **Никаких иллюстраций** в empty/error: заголовок + подпись + одно действие.
7. **Public vs Admin** различаются структурой и плотностью (тёмный sidebar 240/64px, header 56px, breadcrumbs), а не палитрой.

## Шрифты
- `Plus Jakarta Sans` — заголовки и крупные UI-элементы
- `Inter` — основной текст и подписи
- `JetBrains Mono` — ID, даты, технические значения, meta
